World Population Growth Visualization

This project is part of my Data Science internship at Ternovate. The main goal of this task is to visualize world population growth and understand how the population has changed over the years.

About the Project

I used a world population dataset containing yearly population information. Using Python, I explored the population trend and created different visualizations to make the changes easier to understand.

The project focuses on population growth, annual growth rate, net population change, population density, and urban population.
